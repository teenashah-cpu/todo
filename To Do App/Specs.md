# Plan for a To DO app

Specifications
1. Simple to do app. NO frills. basic.
2. It shoud run in a browser
3. Each task has a priority (Low, Medium, High), set when added, shown in the list, and editable afterwards
4. Dark mode toggle, with the choice remembered between visits; defaults to the OS theme if never toggled
5. Each task can have an optional due date; overdue tasks are highlighted
6. Task text can be edited inline by clicking it
7. Tasks can be filtered (All/Active/Done) and sorted (None/Priority/Due date)
8. Empty state message shown when there are no tasks
9. Task counter showing how many tasks are done out of the total
10. "Clear completed" button to remove all done tasks at once
11. Keyboard shortcuts: Escape clears the task input, Delete removes a focused task
12. Tasks can be reordered via drag-and-drop (when filter is All and sort is None)
13. Tasks can be exported to a JSON file and imported back in
